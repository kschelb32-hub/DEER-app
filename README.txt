DEER v6 Progressive Web App

Upload all files in this folder to the root of your existing GitHub Pages DEER-app repository, replacing files with the same names. Keep the repository URL unchanged.

Version 6 changes: Individual Scoring Reference now appears above Individual Scoring Criteria. Each archived assessment has an Email / Share report button that opens the device share sheet (or an email draft where native sharing is unavailable).

The app intentionally retains the v5 local storage keys so existing scores, lock states, notes and archived assessments remain available in the same browser/device after updating. The service worker cache is deer-app-v6.

Saved assessments remain stored on this device/browser and do not automatically sync to other devices. Export or share important reports as a backup.
